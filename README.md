# 📚 Library & Bookstore Management System

A modern desktop application developed using **Python**, **Tkinter**, and **SQLite** to manage both library and bookstore operations efficiently. The system provides inventory management, customer management, borrowing and returning books, sales processing, user authentication, and transaction logging through a clean graphical interface.

---

## ✨ Features

### 🔐 User Authentication
- Secure Login System
- Password Hashing (SHA-256)
- Super Admin & Staff Roles
- Active/Inactive User Status

### 📚 Book Management
- Add New Books
- Search Books
- Inventory Management
- Book Categories
- ISBN Validation
- Quantity & Price Management

### 👥 Customer Management
- Add Customers
- Store Contact Information
- Customer Records

### 🔄 Borrow & Return System
- Issue Books
- Due Date Tracking
- Return Management
- Automatic Stock Updates

### 🛒 Point of Sale (POS)
- Book Sales
- Invoice Generation
- Stock Deduction
- Sales Records

### 📜 Transaction Logs
- User Login History
- Book Operations
- Sales Activities
- Audit Trail
